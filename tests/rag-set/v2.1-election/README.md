## 答案段落送達率

命中規則只比對「法規＋條號」；長條文被切成多段時，拿到任何一段都算命中。送達率另看**含答案的那一段**是否出現在線上實際送進 LLM 的段落中（`rag:eval --json=` 的 `context`：套門檻、預設 Top-K、keep_exact 照設定）：

- `answer_segments.json` 有標註的題目：同法規、同條號，且段落內容（去除空白）包含標註的原句；一題多句時每句都要送達
- 沒有標註的題目：期望條文只有一段，命中即送達
- 「任一」對應 Recall（任一期望條文送達）；「全部」對應 All@k（每個期望條文都送達）

原句取自交付包 `laws/*.md`，不依 chunk_id；`build.py` 會檢查每句都在對應條文中。切段改變後原句仍可用，但要重新確認每句仍完整落在單一段落內。
