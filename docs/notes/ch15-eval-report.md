## 判讀

### 1. Reranker 是這批資料上最重要的一層

E3 相對 E2：Recall@1 40% → 72%、MRR 0.558 → 0.817、文件層級 Top-1 68% → 84%。代價是檢索 p50 從 21 ms 變成 345 ms（20 段候選；M5 Pro）。降級 0 次。

### 2. Hybrid（E2）在法規上讓排序變差

E2 的 Recall@1 比 E1 低（47% → 40%）：E1 第 1 名、E2 掉下去的有 18 題，反方向只有 9 題。這 18 題 E2 的 Top-1 都有 Dense 名次（不是只靠關鍵字進來的），但**一般關鍵字（FULLTEXT）名次高**，RRF 把它推到第 1。法規用語高度均質（「選舉」「罷免」「投票」「委員會」到處都是），二字詞命中沒有區辨力，RRF 又讓關鍵字與 Dense 等權。

Hybrid 的價值仍在精確條號題：精確條號類 E1 36% → E2 57%（Recall@1）。也就是說，**精確詞路徑有用，一般關鍵字路徑在法規上是雜訊**。是否調整（例如一般關鍵字降權、只保留精確詞），依「一次只改一個變因」原則留到下一輪。

### 3. 雙胞胎條文：文件層級正確率是 Recall 看不出的問題

E3 的公職法題目有 10 題 Top-1 是總統法的雙胞胎條文，**正確條文全部在第 2 名**（Recall@5 都算命中）。其中 Q17「縣市長選舉名冊」、Q18「縣市長選票」、B07「當選市長」題目已明講選舉種類，Reranker 仍選了總統法；`prefix_metadata` 雖然把「公職人員選舉罷免法」放在段落前，但模型沒有把「縣市長」對應到「公職人員」。C07「選罷法第九十條」的簡稱本身有歧義（兩部法律都簡稱選罷法），不算系統錯。

反方向（總統法題目 Top-1 是公職法）在 E3 是 0 題。問題是單向的：總統法的條文比較短、用語更通用。

### 4. 精確條號

- **「第63條之1」對不上「第 63-1 條」**：C02 三組都不在 Top-20。Q23（同樣寫「第63條之1」）能找到，是因為題目還有「重新計票保證金」這類內容詞；C02 只有條號
- **只給法規名稱＋條號找不到**：C05「公職人員選舉罷免法施行細則第13條」精確詞「第13條」命中 18 段（各部法規都有第 13 條），文件名稱不在 Chunk 內文中（只在 documents.name），無法縮小到正確的法規。Ch11 的 a02、a04 是同一個問題
- 國字條號（第九十條、第二十四條）能對上：SearchTextNormalizer 已把國字條號正規化，C07、Q25、Q26 精確命中
- 簡稱（選罷法、公投法）不在任何文件中，只能靠條號本身與 Dense

### 5. 失敗題型：口語改寫

口語改寫是 E3 最弱的類別（Recall@1 38%、文件層級 43%）。B03「拍給朋友看我投誰」、B05「阿公手不方便可以幫他蓋嗎」在 Top-20 都找不到；口語詞（拍、阿公、蓋）和條文用語（攝影、家屬、圈選）沒有字面或語意上的重疊。
