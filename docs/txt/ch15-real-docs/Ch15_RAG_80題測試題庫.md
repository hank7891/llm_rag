## 執行方式

1. **單題檢索。** Q01–Q60 各自以獨立查詢跑 E1 Dense、E2 Hybrid、E3 Hybrid＋Reranker。先關閉 Gate 量 Recall@1／5、MRR、法規 Top-1 正確率和 p50／p95。涉及多條者同時記錄任一命中與全部命中。按法規全名＋正規化條號比對，並抽查長條文題目要求的款項是否真的出現在命中的 Chunk。
2. **門檻掃描。** 先核對實際 Gate 的分數來源，再就單題的 `yes` 和 `no` 掃描 0.40–0.75，比較既有 0.59。全題庫設 7 題 `no` 和 4 題 `partial`，其中單題為 7 題 `no` 和 3 題 `partial`。單題 `no` 若漏放一題，擋下率即為 6／7（85.7%）。`partial` 單獨核對找得到的規則與資料缺口。
3. **多輪抽測。** 每組先開一個新對話，按輪次只貼「連續輸入」，保留實際回覆和引用。再將「獨立輸入」各自放到新對話對照，固定檢索設定和 Provider。分輪記錄主題承接、切換法規、漏掉的條文、引用一致性與資料缺口。多輪及獨立對照另行記錄，以維持單題基準的可比性。
4. **端到端回查。** 可先抽 Q39、Q40、Q41、Q46、Q50、Q52、Q53、Q28，保留回答原文、Top-5、引用對應的法規／條號／頁碼及語料外資訊。Q29 與 S05 的長條文案例可檢查條文後段是否因切段或重排截斷而漏掉。

單題表未標記缺口的案件均為 `yes`。`no` 代表本語料缺乏可回答內容。`partial` 代表有可引用的規則，但問題仍有一部分需要其他資料。多輪的獨立版本是同一題的對照問法，題數以輪次計。
