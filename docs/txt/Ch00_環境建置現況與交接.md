## 測試中的觀察

用 curl 測試 Ollama 時發現五件事，影響後續 Ch02、Ch04、Ch07 的實作。

1. **qwen3 預設會開啟思考**：345 個輸出 Token 中約八成是 `thinking`。可用 `"think": false` 關閉，關閉後的效果尚未實測。Ch02 需決定是否開啟，以及是否顯示思考內容。
2. **qwen3 會用簡體中文回答**：即使用繁體發問也一樣。System Prompt 需明確要求「請使用繁體中文（台灣用語）回答」。
3. **bge-m3 輸出維度為 1024**：批次送入 2 段文字得到 2 個向量。Ch07 建立 Qdrant Collection 時 `size` 要設為 1024。
4. **Ollama 預設 num\_ctx 只有 4096**：`ollama ps` 的 CONTEXT 欄位顯示 4096，約等於中文兩三千字，超過會被截斷且不會報錯。.env 已預設 `OLLAMA_NUM_CTX=8192`，Ch02 要帶進請求的 options，Ch04 會做對照實驗。
5. **第一次呼叫較慢**：模型載入需十幾秒，首次 Chat 請求含思考共花 51 秒。載入後模型會在記憶體保留約 5 分鐘。
